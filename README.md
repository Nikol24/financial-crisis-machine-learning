The completed master's thesis provides a comparative analysis of financial market volatility and cross-market relationships during the 2007–2008 Global Financial Crisis and the COVID-19 pandemic.

The research applies financial econometric techniques and machine learning methods to investigate historical market behavior, forecasting performance, and the potential use of predictive models in financial risk assessment.

The Python implementations included in this repository document and extend the analytical methods used in the research. The original thesis findings and subsequent code implementations are presented as distinct components of the project.
