
# Python Source Code

This directory contains the Python implementations developed for the master's thesis:

"Financial Crisis Analysis and Prediction Using Machine Learning"

## Models and Methods

- GARCH (1,1): Financial market volatility analysis.
- DCC: Dynamic Conditional Correlation analysis.
- Diebold-Mariano Test: Statistical comparison of forecasting models.
- LSTM: Financial time series forecasting using neural networks.

## Technologies

Python, Pandas, NumPy, Matplotlib, ARCH, TensorFlow, Scikit-learn.

## Research Scope

The analysis examines six stock market indices:
ATHEX, CAC 40, DAX 40, FTSE 100, S&P 500, and NIKKEI 225.

The research covers the 2007-2008 Global Financial Crisis and the COVID-19 pandemic.
