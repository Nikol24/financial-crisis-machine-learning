
# Financial Market Data

This directory contains the datasets used for the financial crisis analysis.

## Stock Market Indices

- ATHEX (Greece)
- CAC 40 (France)
- DAX 40 (Germany)
- FTSE 100 (United Kingdom)
- S&P 500 (United States)
- NIKKEI 225 (Japan)

## Data Source

Yahoo Finance

## Research Period

January 2003 - December 2023

## Required Format

Historical price datasets should contain:

- Date
- Close

The Python scripts use these columns to calculate returns, volatility, and forecasts.
